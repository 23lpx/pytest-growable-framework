# 测试开发框架异常处理模型

## 1. 核心思想

异常处理的目标不是消灭异常，而是：

-   明确异常责任边界
-   保留错误上下文
-   让上层决定如何处理

基本原则：

> 哪里发现异常，哪里负责识别；是否终止执行，由上层决定。

------------------------------------------------------------------------

## 2. 异常流转模型

``` mermaid
flowchart TD
    A[底层组件发现异常] --> B[转换为框架异常]
    B --> C[向上抛出]
    C --> D[Runner补充执行上下文]
    D --> E[pytest接收异常]
    E --> F[测试失败/报告]
```

------------------------------------------------------------------------

## 3. 分层职责

### Reader层

负责：

-   读取文件
-   解析数据格式

异常：

-   文件不存在
-   yaml格式错误
-   编码错误

转换：

底层异常 -\> DataReadError

------------------------------------------------------------------------

### Model层

负责：

-   数据结构转换
-   数据合法性检查

异常：

-   字段缺失
-   类型错误
-   数据结构错误

转换：

模型异常 -\> ModelError

------------------------------------------------------------------------

### Client层

负责：

-   HTTP请求封装

异常：

-   网络错误
-   超时
-   请求失败

转换：

requests异常 -\> RequestError

------------------------------------------------------------------------

### Handler层

负责：

-   数据提取
-   数据校验

异常：

-   json解析失败
-   提取失败
-   校验失败

转换：

处理异常 -\> ExtractError / ValidationError

------------------------------------------------------------------------

### Runner层

负责：

-   串联执行流程

原则：

-   不吞异常
-   可以增加执行上下文
-   可以记录日志

------------------------------------------------------------------------

### pytest层

负责：

-   测试生命周期
-   测试结果统计

最终：

异常 -\> pytest失败 -\> 报告

------------------------------------------------------------------------

## 4. 异常体系

``` text
FrameworkError

├── ConfigError
├── DataError
│   ├── YamlReadError
│   └── CaseParseError
├── ModelError
├── RequestError
├── ExtractError
└── ValidationError
```

所有异常继承统一基类 FrameworkError。

------------------------------------------------------------------------

## 5. 不推荐方式

不要：

``` python
try:
    do_something()
except Exception:
    pass
```

问题：

-   原始错误丢失
-   pytest无法感知失败
-   调试困难

------------------------------------------------------------------------

## 6. 设计目标

最终：

    数据异常 -> Reader发现
    模型异常 -> Model发现
    请求异常 -> Client发现
    执行异常 -> Handler发现
    测试结果 -> pytest管理

框架提供能力，pytest负责测试生命周期。

------------------------------------------------------------------------
