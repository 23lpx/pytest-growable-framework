# 代码规范

来源：阿里《Java 开发手册》→ 适配 Python。只收**本项目真正会踩**的条目，不搬全本。

---

## 一、命名

| 对象 | 规则 | 例 |
|---|---|---|
| 包 / 模块 | 小写 + 下划线 | `read_yaml.py` |
| 类 | 大驼峰 | `CaseModel` |
| 函数 / 变量 | 小写 + 下划线 | `to_pytest_param` |
| 常量 | 全大写 + 下划线 | `CONTAINS` |
| 内部方法 / 属性 | 单下划线前缀 | `_request`、`_build_url` |

## 二、魔法值〔强制〕

**不允许未经定义的常量直接出现在代码里。**

```python
# ✗
if key == 'contains':

# ✓
if key == ValidationOp.CONTAINS:
```

常量统一放 `src/pytest_framework/entities/constants/` 下，**一个主题一个模块**（如 `constants/validation.py` 里的 `ValidationOp`，以后 error 枚举也放这儿）。

## 三、函数

- **单一职责**：一个函数只做一件事。
- **显式声明返回值**：每个函数都要标返回类型（`-> None` / `-> list[ExecuteCase]`）。**有返回值的必须显式 `return`**；**无返回值的（`-> None`）不写裸 `return`** —— 那是噪音，`pylint` 也会报 `useless-return`。
- **参数校验**：非法参数在函数入口就处理掉，不要带着坏参数往下跑。（本项目的"门禁"主要靠下面第四条的 Protocol，运行时校验按需加。）

## 四、跨层契约用 Protocol〔门禁〕

层与层之间**不靠隐式鸭子类型**。谁要收什么，用 `typing.Protocol` 显式声明出来，统一放 `src/pytest_framework/entities/contracts.py`。

```python
class CaseLike(Protocol):
    method: str
    url: str
    data: dict
    ...

def run(self, case: CaseLike) -> None: ...
```

好处：传错对象在 IDE / 类型检查阶段就报，而不是跑到一半才发现属性不存在。

## 五、依赖方向

**单向**：上层依赖下层。禁止反向依赖、禁止循环 import。

```
cases/ + conftest.py（Composition Root，最外）
    │
    ▼
infrastructure → adapters → usecases → ports → entities
（具体库都在这）  （翻译）    （编排）   （契约）  （内核）
```

## 六、异常

体系见 `docs/framework_exception_design_methodology.md`，代码在 `src/pytest_framework/entities/exception/`：

- `FrameworkError` —— 基类（带 context，上层可补充执行上下文，如 Runner 补 `case_name`）
- `ConfigError` —— 配置错
- `DataError`（父类）
  - `YamlReadError` —— Reader：文件不存在 / yaml 格式错 / 编码错
  - `CaseParseError` —— Model：用例结构不符规范 / 字段缺失
- `ModelError` —— 模型层错
- `ContextError` —— Context：变量不存在 / 路径中间层类型不对 / 占位符语法
- `RequestError` —— Client：网络 / 超时 / 请求异常
- `ExtractError` —— Handler：提取失败 / jsonpath 无匹配
- `ValidationError` —— Handler：校验失败

铁律：**禁止吞异常**（`except: pass` 之类）。底层把异常转换成本层框架异常，并用 `raise ... from e` 保留原始错误；是否终止由上层决定。

## 七、注释

- 公开的类 / 函数写 docstring：**做什么 + 不做什么**。
- 注释解释**为什么**，不复述代码在做什么。
- 不再使用的代码**直接删**（git 有历史），不留注释掉的尸体。

## 八、import

- 一律放文件顶部；禁止 `from x import *`。
- 只 import 用到的。
